# Ficha de Replanteo EFIWATT

Formulario de replanteo en una sola página HTML, sin dependencias externas.
Funciona en el móvil y guarda el progreso en el navegador.

**Sitio:** https://dgavilla.github.io/ficha-replanteo-efiwatt/

## Despliegue

GitHub Pages sirve `index.html` desde la rama `main`. Cualquier push a `main`
republica el sitio automáticamente.
